# FRTC release downloads

Public, binary-only release repository for FRTC Messenger and FRTC Wallet. Application source code is maintained separately in the private [FRTC source repository](https://github.com/adamraihane/frtc).

## Releases

- [FRTC Messenger for Windows, Linux, Android, and legacy Windows](https://github.com/adamraihane/frtc-releases/releases)
- [FRTC Wallet for Windows, Linux, and Android](https://github.com/adamraihane/frtc-releases/releases)

Wallet builds are experimental software for Bitcoin mainnet. They have not had an independent security audit; do not store funds you cannot afford to lose.
